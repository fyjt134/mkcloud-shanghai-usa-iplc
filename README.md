## 先说清楚：沪美 IPLC 到底是什么

IPLC 指国际私有租用线路（International Private Leased Circuit），简单理解就是一条点对点的跨境专用线路：你的数据从上海入口进去，走一条不经过公共国际互联网的通道，直接从美国出口出来。

它和普通美国 VPS 的差别主要在三点。第一是延迟，Mkcloud 官网给的沪美方向端内参考延迟是 124~134ms，而走普通公网的中美访问，第三方测评里普遍记录在 200~400ms 之间，跨太平洋的物理距离决定了专线也快不到哪去，但它把公网绕路、拥堵和丢包那部分水分挤掉了。第二是 IP，专线 VPS 每台机器分配一个独立入口 IP 和一个独立出口 IP，都是独享的 IPv4，不存在和一堆人共享一个出口的问题。第三是稳定性，共享带宽虽然只是峰值速率，但线路本身不走公网，丢包和抖动明显好于普通国际链路。

有一点 Mkcloud 官方文档自己就提醒得很直白：124~134ms 是“端内”参考延迟，不是你访问所有美国网站的实际延迟。你的实际体验还取决于本地宽带到入口的这段、美国出口到目标服务的那段，以及目标服务本身的负载。买之前把这件事想清楚，能避免不少预期落差。

- **不能做对外的网站和服务端**。出口 IP 不支持外部连入，买家页面、支付回调、游戏服务端这类需要“别人能连进来”的业务，这个产品架构上就撑不起来。

## 几个常见问题

**124~134ms 是我访问美国网站的最终延迟吗？**
不是。这是上海入口到美国出口之间“线路内部”的参考延迟。你的全程体验 = 本地到入口 + 端内 + 出口到目标服务，官方文档专门强调过不要拿端内延迟当成访问所有美国网站的速度。

**和我自己买的普通美国 VPS 有什么区别？**
普通 VPS 走公共国际互联网，中美方向高峰期 200~400ms 加丢包是常态；沪美 IPLC 是点对点专线，端内 124~134ms，出口是独享的美国 BGP IP。代价是价格贵了一个量级。

**个人能买吗，还是只对企业开放？**
个人可以买，同样要实名。官网标注有 6000+ 跨境电商客户，用户结构以做美区业务的个人和小团队为主。

**流量超了会怎样？**
流量计费款按上行+下行双向统计，超量后暂停服务，可以自助购买流量重置或提交工单补差价升级。这也是为什么选档前最好先搞清楚自己业务的真实月流量。
